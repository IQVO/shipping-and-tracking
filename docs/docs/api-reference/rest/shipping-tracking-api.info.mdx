REST contract of the shipping-and-tracking bounded context of the retail network, derived from retail-network-docs model/model.yaml (contexts[shipping-and-tracking].rest, .aggregates, .publishes, conventions.errors) and the orchestrator's contracts-delta (G2, G3, G11, G18). It issues shipping labels and owns each package's journey. No schema of this contract carries a ship-to address or any part of it: the address is read from customer-ordering at issue time (GetShipTo), kept only as an encrypted snapshot (purged 30 days after the journey closes) and never returned (ADR RN-0006, ADR 0002 A9). vendor-connectivity calls POST /labels in-organization; the other routes are read by shoppers, customer-ordering and operations tooling. No authentication, consistent with the fleet. Errors are RFC 9457 problem details. The shared problem types are not-found (404), illegal-transition (409), concurrent-update (409) and validation-failed (422), plus one slug per model Err name.
